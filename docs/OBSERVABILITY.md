# Observability Notes

Operational review should cover four signal groups:

- **Health:** service availability and workflow completion.
- **Quality:** schema, validation, freshness, and data-quality outcomes.
- **Performance:** request latency and batch execution behavior.
- **Model operations:** drift, evaluation results, registry state, and release status.

Investigate signals together with the affected dataset, model, workflow, and release identifier to keep incident analysis actionable.
